# Qrow brand

**Mark: B. Return.** One continuous stroke: a Q whose tail runs out and loops back into the ring. The payment goes out; if nobody claims it in 7 days, it comes back. The mark is also the capital Q of the wordmark.

## Files (`export/`)

| File | Use |
|---|---|
| `logo.svg` / `logo-on-dark.svg` | Lockup (mark + "row") on light / dark grounds |
| `logo-mark.svg` / `logo-mark-on-dark.svg` | Symbol alone |
| `favicon.svg` | Tab icon; follows the OS light/dark setting, heavier stroke for small sizes |
| `favicon.ico` | 16, 32 and 48 px, ink mark on a paper tile (works on light and dark browser chrome) |
| `favicon-16.png`, `favicon-32.png` | Same, as PNG |
| `apple-touch-icon-180.png`, `icon-192.png`, `icon-512.png` | App icons: paper mark on the ink board, inside the maskable safe zone |
| `logo-mark-512.png` | Large transparent mark |
| `featured-1200x630.png` | Hackathon featured image and social preview |

Regenerate everything with `npm install` in `brand/`, then `node brand/src/export.mjs` and `node brand/src/build-tokens.mjs` from the repo root.

## Rules

- Ink on paper, or paper on the ink board. The mark is never coral, never a gradient, never outlined.
- Clear space around the mark: half its height. Minimum size: 16 px (use `favicon.svg`, the heavier cut).
- **Coral is reserved for the settled state**: claimed, released, refunded. It's never used for warnings. Caution is amber and a possible scam is crimson, both with an icon and words, so colour is never the only signal.

## Tokens

`tokens.css` (and `tokens.json` with hex values) is generated by `src/build-tokens.mjs`, which also checks WCAG contrast. All 28 text and colour pairs pass AA in light and dark.

## Type

| Role | Face | Licence | How to load |
|---|---|---|---|
| Latin text and display | General Sans 400/500/600 | ITF Free Font License | Fontshare CDN only. **The font files must not be committed or redistributed** (`brand/fonts/` is git-ignored and only used locally to render the PNGs) |
| Arabic (RTL) | IBM Plex Sans Arabic 400/500/600 | SIL OFL 1.1 | Google Fonts |
| Figures in columns (amounts, hashes) | Geist Mono 400 | SIL OFL 1.1 | Google Fonts |

Addresses and amounts are never translated. In Arabic they stay left-to-right, isolated with `<bdi dir="ltr">`.
